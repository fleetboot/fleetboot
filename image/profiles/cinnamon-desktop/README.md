# `cinnamon-desktop` profile

The base fleetboot image plus Cinnamon + LightDM. A "traditional"
desktop metaphor — panel at the bottom, application menu, system tray.
Familiar to anyone moving from Windows or the older Mint distro.

```sh
make image PROFILE=cinnamon-desktop
```

Cinnamon is GNOME-based but lighter than full GNOME and easier to
configure for a locked-down classroom.
