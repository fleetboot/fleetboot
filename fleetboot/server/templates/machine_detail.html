Power control

Every action tries the machine's own command first, then the fleet-wide pdudaemon (/power/control/<action>?alias=<alias>, alias below). Reboot has a third route the others can't: if both fail it arms the soft-reboot signal and the machine reboots itself on its next heartbeat. On and off have no such fallback — an unwired machine simply won't switch.

 
 

Wiring

— defaults to the reported hostname ({{ machine.hostname or 'none yet' }}). Set it by hand for a machine that has never booted, so it can be switched on.

Commands run on the fleetboot host with shell=True as the server user, and override pdudaemon for that action. Anything shell-callable works (curl to a PDU, IPMI, a wake-on-LAN tool, …).
