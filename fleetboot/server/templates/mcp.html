MCP endpoint

fleetboot speaks the Model Context Protocol so an LLM agent (Claude Desktop, Claude Code, any MCP client) can drive the fleet directly — enrol machines, author profiles, kick off builds, reboot hosts, tail events.

Connection

Endpoint{{ mcp_url }}
MethodPOST (JSON-RPC 2.0)
TransportStreamable HTTP — a single JSON body per request; no SSE stream (server never initiates messages).
AuthAuthorization: Bearer <admin secret>  — the same password you used to sign in here.
Protocol version{{ protocol_version }}

Wire it up in a client

Claude Code — from your terminal:

claude mcp add --transport http fleetboot {{ mcp_url }} \
    --header "Authorization: Bearer <admin secret>"

Claude Desktop / other MCP clients — add this to your MCP config JSON:

{
  "mcpServers": {
    "fleetboot": {
      "url": "{{ mcp_url }}",
      "transport": "http",
      "headers": {
        "Authorization": "Bearer <admin secret>"
      }
    }
  }
}

Try it with curl

curl -s -X POST {{ mcp_url }} \
    -H "Authorization: Bearer <admin secret>" \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
