Fleet-wide settings

Power control (pdudaemon)

If you set this, the dashboard's delete + reboot button on a machine without an explicit shell-command falls back to:
curl "http://<pdudaemon_host>/power/control/reboot?alias=<machine_hostname>"
Most machines never need their own per-row reboot command — the PDU side maps the alias (machine hostname) to the right outlet. Leave blank to disable the fallback.
